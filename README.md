# Hi, I'm Issam 👋

I'm a student and aspiring engineer from Ethiopia interested in **Electrical Engineering, Computer Engineering, and Artificial Intelligence**.

I'm fascinated by the intersection of hardware and software: how circuits, embedded systems, and intelligent algorithms can work together to solve real-world problems. I enjoy turning ideas into working systems and exploring how engineering can improve healthcare and everyday life.

- **Artificial Intelligence:** Machine learning and AI applications, particularly language technology.
- **Software Engineering:** Building practical applications across frontend, backend, and mobile.
